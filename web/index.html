Abbinamento

 

Con un computer già abbinato il dispositivo rifiuta i nuovi abbinamenti, così nessun altro può collegarsi. Si apre da qui oppure con un tocco breve sul pulsante BOOT della scheda (il LED lampeggia veloce).

Computer abbinati

    Nessun computer abbinato. Sul computer apri le impostazioni Bluetooth e scegli il dispositivo.

    Il Bluetooth non comunica il nome del computer, perciò vengono numerati. Per riconoscere quale è quale: scollega, osserva quale computer perde il mouse e rinominalo qui.

    Movimento

    Configurazione

    Intervalli 5–3600 s, ampiezza 5–600 px. Un click casuale può attivare ciò che si trova sotto il cursore: lascia 0% se non serve.

    Script

    Uno script è un elenco di passi: move (dx, dy), click, scroll (notches), key (es. F15, Ctrl+Alt+Delete), type (text, ASCII), wait (ms, oppure minMs e maxMs) e repeat (times, steps). Tastiera layout US.

    Automazioni

    Un’automazione esegue uno script a intervalli casuali, solo mentre il jiggler è avviato (massimo 4).

    Sistema

    Sicurezza

    Il token protegge dashboard, API e MCP. Cambialo se è stato condiviso.

    Rete

    Auto: si collega al WiFi di casa e, se non ci riesce, apre la rete di configurazione. Rete propria: crea una rete WiFi protetta con questa dashboard (indirizzo 192.168.4.1), utile dove non c’è WiFi. Tenendo premuto BOOT per 3 secondi si passa da una modalità all’altra. Le modifiche valgono dopo il riavvio.

    Identità Bluetooth

    Il computer vede un solo dispositivo Bluetooth: nome, produttore, VID/PID e indirizzo sono quelli del primo dispositivo abilitato; gli altri aggiungono solo la loro funzione (mouse o tastiera). Lascia vuoti i campi per usare i valori del profilo. Dopo il salvataggio il dispositivo si riavvia e i computer già abbinati potrebbero non riconoscerlo più: dovrai abbinarli di nuovo.

Computers

Pairing

 

Once a computer is paired, the device refuses new pairings, so nobody else can connect. Open the window here, or tap BOOT once on the board (the LED blinks fast). It closes by itself after 3 minutes or as soon as a computer pairs.

Paired computers

    No computer paired. Open pairing above, then choose the device in the computer’s Bluetooth settings.

    Bluetooth does not tell the device a computer’s name, so they are numbered. To tell them apart: disconnect, see which computer loses the mouse, and rename it here. Up to 3 computers can be paired.

    Movement

    Configuration

    Intervals 5–3600 s, size 5–600 px. A random click is always a left click, and it can activate whatever is under the cursor: leave it at 0% if you do not need it.

    Schedule

    Weekly schedules

    While a schedule’s window is open the jiggler runs by itself; it stops when the window ends. Stopping or starting it by hand is respected until the next window opens or closes.

     

    No schedules. Add one to start and stop the jiggler on certain days and hours.

    System

    Security

    The token protects the dashboard, the API and MCP. Change it if it has been shared.

    Network

    Auto: connects to your home WiFi and, if it cannot, opens the setup network. Own network: creates a protected WiFi network that serves this dashboard (address 192.168.4.1), for places without WiFi. Holding BOOT for 3 seconds switches between the two. Changes apply after a restart. Schedules need the home WiFi with internet access to know the time.

    Optional, 8 to 63 characters. Leave it empty and one is generated the first time the own network starts.

    Appearance

    How the device introduces itself to computers over Bluetooth. By default it uses a neutral name. You can give it your own, or pick a real mouse model.

    Leave it empty to use the default name shown in the field.

     

    Changing this restarts the device. Computers already paired will not recognise it afterwards: on each one, remove the device in its Bluetooth settings, then pair it again from Computers → Open pairing.
